# 虎牙拓展更新记录

## [0.1.0-alpha.2] — 2026-11-27

虎牙通过直播间实时连接检测开播与下播。开播卡优先使用主播封面，下播卡可显示直播时长和本场最后采集的热度及贵宾人数。

⚠️ 请先更新到支持拓展 API 1 修订 6 的 BN，再更新虎牙。

### Added

- 订阅虎牙公开房间后，轮播时也会保持实时连接。直播间状态变化时及时核对并按订阅设置推送，连接断开后自动重连。 (ffc80ba93)
- 下播卡保留本场最后采到的直播热度和贵宾人数。有开播与下播时间时显示直播时长。 (e8aff76fd)

### Changed

- 开播卡优先使用主播封面，直播中使用当前房间画面。直播中的默认推送文案可带上当前贵宾人数。 (1653bef72, b9761adad)

## [0.1.0-alpha.1] — 2026-11-23

可用房间号、房间链接或主播昵称添加虎牙订阅，接收开播、正在直播和下播通知。订阅公开房间无需登录虎牙。

### 首版功能

- 搜索结果展示主播头像、房间号和虎牙公开的粉丝数。单张头像加载失败时仍可选择该主播。
- 开播和正在直播的卡片支持同时显示直播热度与贵宾人数。贵宾统计暂时不可用时，其他直播资料仍照常推送。
- BN 按主播 UID 保存订阅。主播更换房间号后，BN 会重新定位直播间，并在资料刷新时更新粉丝数。
- 搜索、资料刷新和直播检查共用请求队列。遇到限流或平台验证时暂停查询，重启后继续等待冷却结束。
