# 虎牙

在 BN 订阅虎牙主播的开播、正在直播和下播通知。需要支持拓展 API 1 修订 5 或更高修订的 BN 宿主。拓展匿名读取虎牙公开房间资料，无需登录虎牙。

1. 在 BN「拓展」页安装并启用与当前 BN 版本兼容的「虎牙」。
2. 到订阅页选择「虎牙」，输入房间号（如 `660000`）、粘贴房间链接（如 `https://www.huya.com/lpl`），或按昵称搜索。重名时可用房间号核对候选。
3. 为需要的通知选择推送目标。BN 用主播 UID 保存订阅，房间号变化后会重新定位并核对主播身份。

搜索结果会显示虎牙公开的头像和粉丝数，已有订阅会在下次资料刷新时更新。图片暂时取不到时会显示昵称首字，仍可按房间号选择主播。订阅列表保存在 BN，可以直接添加公开房间，无需绑定虎牙账号或填写 Cookie。

首次检查建立当前状态。确认主播开播或下播后，BN 按订阅设置推送。主播从直播转入轮播时按下播处理。开启「正在直播」后，BN 在发送周期提醒前会复核房间。断流接续和启动补报沿用 BN 的直播设置。

开播和正在直播的默认卡片都会显示「直播热度」和「贵宾人数」。热度取自房间资料，贵宾人数来自单独的匿名汇总查询。某项暂时取不到时，卡片会省略该项。虎牙返回 0 时照常显示。

每个需要监听的房间通常每分钟检查一次。所有房间、昵称搜索和资料刷新共用一个请求队列，相邻业务请求至少间隔三秒。订阅较多时，一轮检查可能超过一分钟。虎牙限流时，拓展保存等待期限，重启后继续等待。遇到登录拦截或平台验证时，所有房间一起暂停，冷却后自动复查。房间受限或状态不明确时保留上次确认的直播状态，可在 BN 的问题列表查看原因。

拓展和订阅来源图标取自[虎牙直播官方标志](https://hd.huya.com/pc/contactUs/)，标志及相关商标的权利归其权利人所有。

## 本地开发与打包

在仓库根目录运行 `vp install` 和 `vp run dev:apps`，再从开发版拓展页挂载 `extensions/huya`。运行以下命令生成可安装的 ZIP。

```sh
vp run -F @bilibili-notify/extension-huya build
vp exec node scripts/pack-extension.mjs --id huya
```
