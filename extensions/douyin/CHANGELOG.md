# 抖音订阅源更新记录

## [0.1.0-alpha.4] — 2026-11-27

抖音在轮询发现开播后接入直播间。实时连接可接收下播和弹幕事件，并统计本场礼物件数。

⚠️ 请先更新到支持拓展 API 1 修订 7 的 BN，再更新抖音。

### Added

- 收到直播间的下播事件时及时推送。实时连接不可用时由轮询继续核对直播状态。 (f97936577, a944be02a, b04e5ffe0)
- 可按关注名单推送「特别关注弹幕」。弹幕条数与礼物件数可计入本场统计。 (f97936577, ec63c0f05)

### Changed

- 默认作品文案区分抖音作品和视频，默认直播文案在有起播时间时显示已播时长。 (4f0a5bee7, b9761adad)

### Fixed

- 扫码状态查询遇到限流时，按抖音给出的时间等待再查。 (4aa4d3eb9)

---

## [0.1.0-alpha.3] — 2026-11-21

抖音短链遇到限流时会遵守平台给出的等待时间，请求超时后可重试。

### Fixed

- 短链重定向返回 HTTP 429 时，后续请求遵守平台的 `Retry-After`。平台返回 HTTP 408 时，短链解析会报告可重试的超时。 (080ee96c4, c96461ce7)

---

## [0.1.0-alpha.2] — 2026-11-20

抖音图文卡可展示话题与收藏数，直播卡在平台提供数据时会显示分区、开播时间和准确的累计观看。登录恢复会保存平台更新的凭据。

⚠️ 此版本需要支持拓展 API 1、修订号 3 的 BN，请先更新本体。

### Added

- 作品卡保留图文文案里的话题，并补充转发、评论、点赞和收藏计数。 (9fecb7f9b, 268994cdf)
- 直播在平台提供数据时展示直播分区、开播时间和累计观看。 (5dd1143bf, c34045615)

### Fixed

- 退出或换号时立即停用旧凭据。启动校验发现登录过期时提示重新登录，验证成功后保存平台更新的凭据。 (461114117)

---

## [0.1.0-alpha.1] — 2026-11-17

登录账号的头像下载失败后会自动退避重试，临时网络故障恢复后无需重新扫码。

### Changed

- 头像重试与登录状态分离，下载失败仍保留已验证的登录；退出、换号或停用时取消旧账号的重试。

---

## [0.1.0-alpha.0] — 2026-11-14

可在系统账号页扫码登录抖音，订阅博主的视频、图文和直播，并在群聊预览作品链接。
