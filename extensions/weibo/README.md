# 微博订阅源

在 BN 接收已关注博主的新微博。需要支持拓展 API 1、修订号 1 或更高版本的宿主。

1. 在拓展页安装微博拓展并启用。
2. 打开「系统 → 账号」，用微博 App 扫码并确认。BN 核实账号后先显示昵称，头像下载完成后自动显示。重启时会用已有会话重新读取头像。
3. 用这个微博账号关注要订阅的博主，再到 BN 订阅页选择「微博」。输入完整昵称（可带 `@`）、数字 UID，或粘贴 `https://weibo.com/n/昵称`、`https://weibo.com/u/12345` 这样的主页链接。
4. 开启这条订阅的作品通知，选好推送目标。首次检查建立基线，此后出现的新微博才会推送。

一个账号的全部订阅共用一条关注流。有启用作品通知的订阅时，每分钟检查一次。支持正文、长文、图片和视频卡片信息。转发会在正文中注明可用的原作者和原文，卡片链接指向博主自己发布的那条微博。

微博限制请求频率时，所有取数入口共用同一冷却时间。重启也会遵守微博给出的等待期限。登录暂时核实不了时，BN 保存原有凭据并退避重试。提示安全验证时，请在微博完成验证，再到系统账号页重新扫码。

登录会话保存在 BN 的加密凭据存储中，启动时会重新核对 UID。重启、重新启用、切换账号或为博主重新开启作品通知时，BN 会从当时的关注流开始判新。停机期间的历史微博不会补发。

## 本地开发与打包

在主仓根目录运行 `vp install` 和 `vp run dev:apps`，在开发版拓展页挂载 `extensions/weibo`。制作可安装的 ZIP 使用下列命令。

```sh
vp run -F @bilibili-notify/extension-weibo build
vp exec node scripts/pack-extension.mjs --id weibo
```
