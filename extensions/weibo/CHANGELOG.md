# 微博拓展更新记录

## [0.1.0-alpha.1] — 2026-11-23

用微博 App 扫码登录后，可按昵称、UID 或主页链接订阅已关注的博主。新微博会推送到所选目标，卡片可展示图片、话题和超话信息。

⚠️ 请先将 BN 更新到支持拓展 API 1 修订 5 的版本。首次启用订阅时，从当时的关注流开始监听。

### 首版功能

- 使用微博账号关注博主后，在 BN 开启作品通知。转发微博会保留可用的原作者和原文，卡片链接指向博主发出的转发。 (700318812, 0b4853ea6)
- 卡片可展示微博提供的发布设备、发布地和超话资料。某条微博的长文暂时取不到时，其他新微博仍会推送。 (415d22696, 413a08aca, e24e13104, bf3565ba7)
- 微博限制请求频率时会按平台给出的时间暂停。遇到安全验证时，账号页会提示完成验证后重新扫码。 (35a75a90e, 8b84d0813)
