# 假源(开发用)

一个**开发用**的订阅源拓展,背后不连任何平台。真平台(抖音)接进来之前,拿它在真机上把「订阅源」那条路走一遍:平台选择里多出一档「假源」、输入框的提示、解析门交回的候选、各种失败怎么显示,以及拓展页上的视图(ADR-0019 决策 34)。

它走的是正式的注册口(`ctx.registerSubscriptionSource`),与以后真的订阅源拓展是同一条路:解析门,加上拓展页上几颗造上报的按钮(见下面「上报按钮」)。

## 在开发版里装上

1. `vp run dev:apps` —— 它会顺带 watch 打包仓里每个拓展,`dist/` 自己就有了。只想构建一次的话:`vp run -F @bilibili-notify/extension-fake-source build`。
2. 面板左下角的 devtools →「装一个仓里的拓展」→ 选 `fake-source` → 执行。它把 `dist/` 软链进 `<dataDir>/extensions/`,当场生效。
3. 拓展页 →「假源(开发用)」→ 拨开开关。
4. 订阅页 →「添加 UP 主」→ 平台选「假源」→ 在输入框里随便输点什么。

改了代码:按 devtools 的「重载(换掉代码)」,或者开着「改完自动重载」。不用了:「卸掉一个装好的拓展」。

## 输入什么会怎样

| 输入 | 解析门做什么 | 面板上看到的 |
| --- | --- | --- |
| 随便什么字 | 按这句字现编三个候选:有头像有粉丝、有头像不报粉丝、没头像只报粉丝。同一句字永远是同一组 | 三个候选,选一个进配置弹层 |
| `空` | 回空表 | 没找到 |
| `慢` | 一直不回,直到宿主不等了(15 秒) | 504:解析门超时 |
| `坏` | 抛错:「cookie 已过期,平台要求重新登录」 | 502:拓展查询出错,带着这句原话 |
| `乱` | 交回宿主必须拒的候选(一张 SVG 头像、一个负的粉丝数) | 502:候选不合规矩,点名哪两处 |

## 上报按钮

拓展页 →「假源(开发用)」的头卡上有七颗按钮。视图里的按钮带不了「点的是哪一行」(ADR-0019 决策 42),所以每颗都**一次作用于名下所有开着的订阅**:按外部 id 报,同一个人建了两条订阅也只报一次(BN 自己扇出),停用的不报。按完头卡底下多一行「报给了几个人」;一条开着的都没有时什么都不报,那一行说「还没有开着的订阅」。

造出来的数据是**确定的**:序号一下一个(只在真报出去时才往前走),不掷骰子;链接都落在 `*.fake-source.invalid` 上,点了也不会跑到别人家。图是 64×64 的纯色 png。

| 按钮 | 报什么 | 去哪儿看 |
| --- | --- | --- |
| 报一条作品 | 第 N 条作品:单数是图文(正文 + 三张图),双数是视频(封面、标题、时长、简介、播放数);都带赞 / 评论 / 转发 | 眼下看不见:BN 收下了、还没人接(出卡与推送是 ④ 的下一片),群里收不到、面板上也没有;只有头卡底下那行「报给了几个人」 |
| 开播 | 第 N 场:链接、开播时刻、标题、封面、分区(聊天 / 游戏 / 唱见轮着)、人数 100、点赞、简介 | 首页「正在直播」多出这几条订阅 |
| 下播 | 同一场的链接,补上开播时刻 | 首页那几条没了 |
| 报资料 | 名字「假名字 · 第 N 版」、粉丝数、头像(报资料专用的四张轮着换,与建订阅时的候选头像不重样) | 订阅页那几条的名字 / 粉丝 / 头像当场换 |
| 报直播状态 | 「在播」,人数每按一次涨 100;没开播就按,从这一刻算一场新的(演 BN 重启过、开播没见着) | 首页「正在直播」有它、人数跟着涨 |
| 报一条带坏图的作品 | 一条三张图的作品,第 2 张是 SVG | 拓展详情页的「上报问题」:一条「丢了」,点名 `images[1]`;作品照样收下(少那一张) |
| 报一条多一格的作品 | 一条作品多带一格 BN 不认识的 `danmaku`(弹幕数,契约明说不收) | 「上报问题」:一条「拒了」,点名 `danmaku`。拒是意料之中,按钮不报错;BN 要是收下了,按钮反倒报错 |

### 真机怎么看

1. 照上面装好、拨开开关;订阅页 →「添加 UP 主」→ 平台选「假源」→ 输入「阿梓」→ 三个候选各建一条(想看「停用的不报」,就把其中一条停用)。
2. 首页开着一个标签页,拓展页 → 假源开着另一个。
3. 按「开播」→ 首页「正在直播」出现开着的那几条(标题「假直播 · 第 1 场」、分区、100 人);连按两下「报直播状态」→ 人数 200、300;按「下播」→ 没了。
4. 按「报资料」→ 订阅页那几条的名字变成「假名字 · 第 1 版(…)」、头像换色、粉丝数变;再按一下又换一版。
5. 按「报一条带坏图的作品」「报一条多一格的作品」→ 拓展详情页出现「上报问题」框:每个开着的人各一条「丢了」(点名 `images[1]`)、各一条「拒了」(点名 `danmaku`)。
6. 把订阅全停用再按任意一颗 → 头卡底下那行说「还没有开着的订阅」,首页 / 订阅页 / 上报问题都不动。

七颗按钮报的形状都由 `apps/server/src/__tests__/fake-source-buttons-e2e.test.ts` 装真的假源、在真 BN 上核过(「报一条作品」今天只有这条测试看得见它被收下了)。
