# 假源(开发用)

一个**开发用**的订阅源拓展,背后不连任何平台。真平台(抖音)接进来之前,拿它在真机上把「订阅源」那条路走一遍:平台选择里多出一档「假源」、输入框的提示、解析门交回的候选、各种失败怎么显示,以及拓展页上的视图(ADR-0019 决策 34)。

它走的是正式的注册口(`ctx.registerSubscriptionSource`),与以后真的订阅源拓展是同一条路。眼下只有解析门;以后会加「报一条作品 / 开播」的按钮。

## 在开发版里装上

1. `vp run dev:apps` —— 它会顺带 watch 打包仓里每个拓展,`dist/` 自己就有了。只想构建一次的话:`vp run -F @bilibili-notify/extension-fake-source build`。
2. 面板左下角的 devtools →「装一个仓里的拓展」→ 选 `fake-source` → 执行。它把 `dist/` 软链进 `<dataDir>/extensions/`,当场生效。
3. 拓展页 →「假源(开发用)」→ 拨开开关。
4. 订阅页 →「添加 UP 主」→ 平台选「假源」→ 在输入框里随便输点什么。

改了代码:按 devtools 的「重载(换掉代码)」,或者开着「改完自动重载」。不用了:「卸掉一个装好的拓展」。

## 输入什么会怎样

| 输入 | 解析门做什么 | 面板上看到的 |
| --- | --- | --- |
| 随便什么字 | 按这句字现编三个候选:有头像有粉丝、有头像不报粉丝、没头像只报粉丝。同一句字永远是同一组 | 三个候选,选一个进配置弹层 |
| `空` | 回空表 | 没找到 |
| `慢` | 一直不回,直到宿主不等了(15 秒) | 504:解析门超时 |
| `坏` | 抛错:「cookie 已过期,平台要求重新登录」 | 502:拓展查询出错,带着这句原话 |
| `乱` | 交回宿主必须拒的候选(一张 SVG 头像、一个负的粉丝数) | 502:候选不合规矩,点名哪两处 |
