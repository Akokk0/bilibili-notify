## 说明与诊断数据

宿主说明使用`logText`，业务包使用包自有`*.log.*`键，B站与桥接使用所属字典；面板控制台使用面板`logText`。说明在输出时读取当前语言，固定使用平实层。普通交互仍沿原取字入口。

原始Error及cause、失败码、事件/操作名、身份与ID、用户自填值、来源描述、验证器的原始拒绝原因作为诊断数据保留。皮肤回落的回调载荷、问题文字、HTTP返回原因、协议close reason和模型输入保持既有契约；日志中可能保留这些数据产生时的原文。历史日志保留写入时的文字。

5-38至5-66已分别核对日志等级、去重、任务节流、错误上下文与实际读者；发送结果不明的防重发修复独立落在5-45与5-47。迁移修订号53、备份版本23保持。
