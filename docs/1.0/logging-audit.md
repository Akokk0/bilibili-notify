# 日志接线审计

2026-11-08，范围按[ADR-0039](../adr/0039-localized-logs.md)。本记录覆盖服务端、业务包、随仓拓展和面板控制台。桌面启动器的12处日志写入已清点，新增测试入口等待主人确认，日志整理整体尚未结束。第5期的界面译文仍按[第5期计划](./phase-5-plan.md)继续。

## 说明与诊断数据

宿主说明使用`logText`，业务包使用包自有`*.log.*`键，B站与桥接使用所属字典；面板控制台使用面板`logText`。说明在输出时读取当前语言，固定使用平实层。普通交互仍沿原取字入口。

原始Error及cause、失败码、事件/操作名、身份与ID、用户自填值、来源描述、验证器的原始拒绝原因作为诊断数据保留。皮肤回落的回调载荷、问题文字、HTTP返回原因、协议close reason和模型输入保持既有契约；日志中可能保留这些数据产生时的原文。历史日志保留写入时的文字。

5-38至5-66已分别核对日志等级、去重、任务节流、错误上下文与实际读者；发送结果不明的防重发修复独立落在5-45与5-47。迁移修订号53、备份版本23保持。

AST扫描取得734处方法调用候选，分布在121个文件。扫描也会收进同名的非日志方法。34处未被简单的`logText/packageText`首参数识别，读者核对如下：

同时检查裸`log(...)`、`consoleErrorRedacted`、`stderrLineRedacted`、桌面控制台与原生文件写口。启动配置加载和载荷回退沿原单行出口；首次生成面板凭据仍是既有的一次性启动提示。前端字段缺说明的DEV告警单独完成四语接线，开发环境开关保持。

这份清点保留原始候选清单和逐模块测试证据。取字及字典守卫继续核对真实读者、键、参数、输出时机和平实层；中文棘轮的日志参数排除只决定该条机械扫描的范围。已迁移的日志片段逐条核销原精确登记，输入协议及回调载荷的剩余登记继续严格检查。

## 桌面启动器待办

`apps/desktop/src-tauri/src/main.rs`中`append_launcher_log`有12个实际调用：Dock重开、启动器装配、托盘就绪/失败、服务启动/就绪、正常退出后的重启、异常退出、停止服务、启动失败、退出时停止失败、Dock切换失败。

拟沿真实`launcher.log`写入口测试：追加和时间戳、说明与原诊断分离、写入失败不影响启动、日志不含桌面令牌；现有退出判定与就绪测试继续约束生命周期。启动器尚未取得宿主语言设置，使用已定的简中平实启动回落；现有系统语言读取只负责下载镜像选择，不扩大为第二份应用语言配置。不得为日志增加请求或读取宿主配置的旁路。

该测试入口确认前，桌面生产代码保持现状。最终验收须包含这一项或由主人明确调整范围。

新增审计说明只修正文档和守卫范围注释，机械匹配逻辑不变；对应3个守卫文件148通过/1既有诊断跳过。Knip文件及导出/类型扫描均为0项。发行载荷装配通过；CI独立迁移耗时检查通过，满量70.1秒、四分之一量18.5秒、比值3.79，符合满量不超过5分钟及比值不超过5.5的原门禁。完整命令、初跑失败、重跑结果及候选分类证据随主仓`.bn-design`交付记录归档。桌面启动器待办按上一节保留。
