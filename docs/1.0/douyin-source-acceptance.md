## HTTP 修复与证据解释

- 详情保留 aid=6383、作品编号与必要 SDK 签名；同一 Cookie 的相邻对照中，通用环境参数触发验证，业务请求返回匹配视频。图文缺 aid 时返回 images_base，补回后返回匹配详情。
- 搜索使用每次新请求 nonce，服务端会话 Cookie 独立续传和保存。其他昵称随后返回数据；已成功昵称上的相邻对照两种令牌都能成功，不能排除缓存或平台状态变化，也不能声称某个字段是唯一根因。
- 普通取数响应的 Cookie／令牌保存失败如实返回并允许后续重试；旧 Cookie 的迟到 401 不清除已更新凭据。
- 上游 filter_reason 不等于“作品不存在”。未知过滤现返回暂时不可用，按端点退避并只放行一次恢复探测；HTTP 404 与明确私密账号保留原分类。此项在来源公开入口先红后绿，主仓提交 `85f7ae0aa`，仓外提交 `0964234`。
- 首版使用方式是先在系统账号页扫码。普通匿名取数尚未通过真实验收，不承诺免登录取数或长期不受平台验证。

## 临时浏览器实验

主人批准的一次官网对照已结束：官网无需人工验证码即可读同一作品，整个临时浏览器退出后，原 HTTP 策略仍受验证。后来成功来自 HTTP 端点参数修复，使用原隔离实例凭据即可，不依赖实验交接会话。凭据只在临时内存中交接，未覆盖原加密存储。

正式浏览器登录、常驻抖音网页和远程操作入口均未接入。卡片截图使用现有渲染器，其独立临时 Chrome 只接受内嵌内容，不用于抖音登录或数据请求。
