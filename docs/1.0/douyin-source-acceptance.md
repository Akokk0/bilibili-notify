# 抖音订阅源验收（2026-11-13）

[首版范围](../adr/0047-douyin-source-parity.md) · [第六期片表](phase-6-plan.md)

先用公开的 `create-bn-ext@0.1.0-alpha.3` 创建独立工程（`akokko.douyin`），从来源公开入口验证，再移到 [extensions/douyin](../../extensions/douyin)（官方 ID 为 `douyin`）。两者使用同一个宿主契约，身份与凭据按 ID 隔离。官方版按普通拓展安装，不内置于 BN 核心。尚未上架市场。

| 操作 | 已验证 | 尚未验证 |
| --- | --- | --- |
| 系统 → 账号 | 首页 nonce 协商修复后，持有人在原隔离实例通过纯 HTTP 扫码登录；宿主确认 `logged-in`。换包重新装载后，从加密凭据恢复并由平台账号接口再次确认。模拟平台覆盖二次验证、重试、退出、过期及来源间隔离；内置浏览器已验账号页。此前 2156 失败记录保留。 | 真实平台若要求短信或网页二次验证，仍需持有人完成；本轮正常登录没有触发这两条分支。 |
| 查找与订阅 | 固定响应覆盖主页、分享短链、抖音号及昵称候选。真实登录后补齐搜索环境及业务参数，「人民日报」返回 10 位候选；真实作者资料读取成功；面板接口返回的 10 位候选均带宿主下载的头像。人民日报和央视新闻的首次订阅轮询分别取得 19／20 条作品，建立基线。仅改 Referer 的对照仍受验证，不能将修复归因于单一头字段。 | 真实主页／短链／精确抖音号，以及真实新增作品后的轮询变化。 |
| 作品和群聊 | 固定响应验证视频、图文、翻页、置顶、去重、重启基线和群里解析未订阅作者的作品；真实首次轮询取得作品列表，未将既有作品当作新增上报；旧账号的迟到响应不能触发推送。早期匿名解析[人民日报的一条公开视频](https://www.douyin.com/video/7627083063436053769)返回 HTTP 403（`douyin.signature`）；本轮先遇 HTTP 200 空正文／滑动验证；最终改用作品业务字段与 SDK 签名的独立端点策略，正式构建已取得上述真实公开视频详情。相邻对照中，同一 Cookie 的通用参数请求仍受验证，最小请求返回匹配作品。 | 真实图文、配图下载与分享短链，以及群聊完整链路。 |
| 直播 | 固定响应验证首次观测、开播、直播、下播、重复及失联。真实候选已读取并上报未开播状态；这次未进入直播间接口。 | 真实在播房间、可以核实的开播／下播变化。 |
| 宿主端到端 | 实际安装官方格式 ZIP；外部平台响应与推送接收端用本机夹具。验证登录、资料、卡片内容、四条送达历史，以及两条作品和一场直播的统计。 | 未向真实 IM 群发送验收消息。 |
| 官网浏览器先行验证 | 独立 Chrome 临时上下文扫码及官网账号确认成功；Cookie 只在内存交给现有拓展后，HTTP 账号校验成功，昵称搜索仍遇验证。第二轮在官网页面仅传搜索业务参数，返回 10 条用户结果且无正文验证指令；保留旧签名／环境参数的对照请求失败。会话已关闭，凭据未落盘。 | 这是本机有界面的独立原型。尚未实现宿主正式浏览器契约、来源候选转换及后续取数，也未验证无头模式、重启恢复或远程人工验证；不能视作系统账号页和订阅源已经可用。 |

按主人要求回到 HTTP 路线后，先修正昵称搜索的签名策略，再补登录前的首页 nonce 协商。签名回归的合成向量由冻结官网脚本产生，运行拓展时不执行网页脚本。匿名实测两次首页均为 200，第二次 1,079,725 字节，随后请求已带服务端访客标识；取码及一次待扫轮询均为 200、错误码 0、状态 `new`。首页专用响应上限调整为 4 MB，其他登录接口仍为 1 MB。随后真人扫码及重新装载后的恢复均已通过。补齐搜索能力字段和搜索页来源后，正式构建和原隔离宿主均返回 10 位真实候选；资料、头像和两个样本的作品列表成功。详情另改用业务字段和 SDK 签名，正式构建已取得真实视频内容。普通取数续传 Cookie／令牌并保存到机密存储，旧响应不能清除新凭据；62 项拓展测试、2 项宿主端到端以及仓外六项门禁通过。尚未证明普通匿名取数的首次会话初始化、真实图文、分享链路和在播房间可用，不能据登录／搜人成功提前结项。

本轮宿主与拓展需要 API 1 / revision 1。已发布的 SDK `0.1.0-alpha.0` 与创建器 `0.1.0-alpha.3` 不包含全部新契约；仓外工程通过随工程固定的本地预览包构建，官方版直接使用 workspace 依赖。未发布 SDK、创建器或主程序新版本。

复验：仓外使用 `vp install --frozen-lockfile` 和 `vp run verify`。主仓从 `extensions/douyin/src/__tests__/*.test.ts` 运行来源测试，从 `apps/server/src/__tests__/douyin-source-e2e.test.ts` 运行安装至推送的回归。真机登录只在本机系统账号页操作，不保存二维码、验证码或凭据作为交付证据。

主人批准的一次临时官网对照已完成：官网无需手动验证即可读到同一作品，关闭浏览器进程后，原 HTTP 参数策略仍受验证。该结果没有证明“只更新 Cookie”足够；后续成功来自 HTTP 端点参数修复，使用原隔离实例凭据即可，无需这次浏览器交接的会话。临时浏览器和研究 HTTP 客户端均已关闭，没有正式接入浏览器能力。另两个新昵称样本仍受平台验证，搜索不能从成功样本外推为普遍稳定。
