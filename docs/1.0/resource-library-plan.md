## 页面与归属

- 复用全宽`HeroStrip`、`SectionNav`、`GlassPanel`、按钮、输入框、弹窗及图标；字号与其他页面使用同一阶梯。
- 桌面为分类侧栏加内容网格，窄屏用现有侧栏的横向分类形态；保留现有全局布局。
- 分类提供搜索、来源标记、预览及适用操作。内置条目提供“复制并编辑”，已使用条目显示用途。
- 资源库不直接替换当前业务选择；导入完成提示去对应页面选用。

## 实施前保持的事实

- 资源库是统一界面，当前不要求搬目录或抬迁移修订号；需要新增盘格式的切片单独核对迁移/备份，不能提前断言永远不迁移。
- R4已将人格内容管理从AI设置草稿抽离，数据继续沿用原设置；独立保存有版本与引用保护，旧页面不能整份写回覆盖新资源。
- R4落定性格文件版本1、256KB、严格字段与本地身份重建，契约见`apps/contract/src/persona.ts`，实现细节见ADR-0038实施记录。
- 当前原件、内置项、正在使用的引用继续由现有模块约束；不提供静默覆盖或自动启用。
