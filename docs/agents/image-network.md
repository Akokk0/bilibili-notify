# 图片下载的地址范围

系统 → 运行 → 图片下载网络，通过 `core.network.imageAllowedCidrs` 设置额外允许的 IPv4／IPv6 CIDR，每行一个。默认空列表，仅允许公网。常见路由器 FakeIP 环境可用快捷操作填入 `198.18.0.0/16`；使用其他范围时按实际网络填写。保存后用于新的图片请求。

配置范围内的地址可以被图片请求访问，包括内网服务，因此只添加使用者信任的代理或图床范围。此设置同时覆盖宿主、B 站账号头像、所有内置集成与拓展抓图；普通 HTTP 请求不变。来源与拓展不能通过 `fetchImage` 的参数扩大范围。

运行时通过 `AppRuntime.createImageFetcher` 为每个调用方注入同一份设置读口，保留调用方原有的请求身份与图库写口。实际地址仍在建立连接时检查，重定向逐跳检查；策略变化生成新的检查函数，后续请求不使用旧策略的连接池。损坏范围不能让检查退化为全部允许。

头像下载失败不会让账号退出登录。B 站在既有登录心跳中补抓缺失头像；抖音独立后台重试，成功后停止，退出、换登录或停用时取消。配置兼容范围后不需要重新扫码，已有失败需等待下一次补抓或重启服务后恢复。

决策与边界见 [ADR-0053](../adr/0053-image-address-ranges.md)。
