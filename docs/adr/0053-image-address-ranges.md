# ADR-0053：图片下载允许显式配置受信任地址范围

- **状态**：2026-11-17 主人要求由 BN 支持 FakeIP 或自定义范围，并确认测试范围。
- **影响面**：全局设置、所有宿主与集成抓图口、系统运行设置。
- **修订**：ADR-0025 决策 8 的默认内网拦截增加使用者明确配置的地址例外。

## 背景

路由器代理把公网图床解析到 FakeIP 保留地址时，原有图片地址检查会拒绝下载。使用者希望直接在 BN 设置兼容范围，不依赖调整路由器。

## 决策

1. 图片下载默认仍仅允许公网地址。使用者可通过全局 `network.imageAllowedCidrs` 添加受信任 IPv4／IPv6 CIDR，缺省为空；提供常用 FakeIP 范围的快捷填入。
2. 例外只影响抓图。账号头像、订阅图片、宿主图片与拓展抓图使用同一份宿主策略，拓展不能通过调用参数另行放宽。普通 HTTP 请求不改变。
3. 保存时严格校验，读取坏条目不扩大范围。设置保存后用于新的抓图请求，撤销范围后的新请求不能沿用旧策略连接。
4. 检查仍绑定实际连接解析出的地址，并对每个重定向目标重新检查。超时、图像嗅探、体积限制与 Cookie 隔离保持原有约束。

## 明确不做

- 不默认允许全部内网或保留地址，不因发现 FakeIP 而自动放行。
- 不关闭全部图片地址检查，不把检查选项交给拓展或来源自行选择。
- 不修改使用者的路由器、系统 DNS 或代理规则。

## 后果

配置的地址范围成为使用者主动信任的访问范围，可覆盖其私有网络；界面明确说明这一含义。留空时保留原有保护，兼容环境不需要扩大其他网段。
