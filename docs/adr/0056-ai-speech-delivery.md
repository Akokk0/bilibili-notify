# ADR-0056 女仆推送语音

状态：2026-11-18 已确认。

## 决策

- 作品点评、下播总结与定时锐评可朗读女仆实际生成的文字。卡片、原文、链接和模板保持各自的投递方式。审批通过后才合成最终稿。
- 发送方式有仅文本、语音加文本、仅语音三档。默认仅文本，每个目标可以覆盖或恢复继承。语音加文本先投递原消息。
- 搜索、语音在 AI 设置中各有独立页签。语音接入可配置地址的 OpenAI 兼容语音合成服务，独立保管密钥，全局共用模型与音色，面板可试听。
- 同次推送中相同文案和音色复用一次合成。每段最多发一条语音，以免长锐评连续刷屏。
- 目标不支持、合成失败、内容超限或平台明确拒收时，确保文字只发一次，并保留诊断。平台接收结果不确定时，记录待确认，避免重复发送。

## 明确不做

首版只读女仆的原话。为语音重新生成摘要会改变已审批的文字，逐群分配音色会增加配置成本，这两项都留在本次范围之外。
