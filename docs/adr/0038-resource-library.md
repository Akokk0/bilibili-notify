# ADR-0038：资源库作为可复用内容的统一管理入口

- **状态**：2026-11-06主人认可统一资源库方向。
- **影响面**：面板资源管理入口、技能与性格的导入导出、原页面的选用入口。
- **修订**：[ADR-0022 决策11](0022-data-generations-and-migration.md)的面板管理范围；保留其素材存储和生命周期边界。
- **另行修订管理位置**：[ADR-0003开工前决策4](0003-agent-skills.md)的AI页技能编辑入口、[ADR-0014决策20](0014-card-skin.md)的卡片页皮肤库；保留独立保存、原业务页选择与专用编辑器。
- **依赖**：[技能格式](0003-agent-skills.md)、[界面皮肤包](0002-skin-pack.md)、[卡片皮肤包](0014-card-skin.md)、[语言与口吻](0037-i18n.md)。

## 背景

素材库现在只管理反复使用的图片和字体；技能、性格和两种皮肤分别在其他页面管理。它们同样是主人会收藏、编辑和分享的内容，统一入口能减少寻找与重复管理。

## 决策

1. 面板的素材库扩为“资源库”，首批六类：图片、字体、女仆技能、女仆性格、界面皮肤、卡片皮肤。文字模板方案作为后续分类，不先放没有实现的入口。
2. 资源库负责新建、编辑、复制、删除、导入与导出。业务页面保留选择、应用与“管理资源”快捷入口；同一资源只有一套管理实现。现有编辑器与基础组件继续复用。
3. 统一的是管理入口。图片和字体继续由`library/`托管；技能继续是独立`SKILL.md`；性格继续沿用现有设置与引用；两种皮肤继续由各自的皮肤库管理。皮肤自带资产随包保存，对话附件继续归图库。
4. 图片与字体使用原文件，技能使用`SKILL.md`，性格使用有格式版本的JSON，界面皮肤和卡片皮肤使用各自已有ZIP格式。单项导入导出优先，首批不引入跨类型的整库归档格式。
5. 性格包包含名称、人格字段与作品点评/直播总结场景提示词；导入生成本地身份，不携带本地应用指针。内置性格导出的是当前语言内容的可编辑快照。
6. 导入先校验和入库，再由主人在原业务页面应用；导入本身不切换当前性格或皮肤。同名/同标识冲突显式呈现，默认保留原件、新建副本，不静默覆盖。
7. 内置资源保持只读，允许导出或复制后编辑。删除继续遵守各类资源的引用检查与当前使用保护，不能因为集中管理而绕过原来的约束。

## 明确不做

- 不把皮肤包内每张图片、每份字体展开成独立素材项；它们与所属包共同管理。
- 不将对话、历史记录、账号凭据和运行中的拓展作为本批可分享资源。
- 不为统一入口重写已有皮肤格式、编辑器或建立第二份资源数据。

## 后果

资源库从两个资产分类变为多个内容分类，导航与操作需要统一；各类预览、校验与引用语义仍由所属模块负责。原页面需要从完整管理调整为选用，同步处理草稿、查询缓存与跳转定位。技能和性格需补齐可往返的导入导出能力。
