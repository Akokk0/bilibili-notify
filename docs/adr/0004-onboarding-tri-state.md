# ADR-0004:新手指引 —— `skipped` 的三态

- **状态**:**已实现,未发版**(2026-08-29 五轮拷问定案 → 08-30 审查回炉 + 三态改版,24+ commit,全量门禁绿)
- **记录方式**:⚠️ **事后追认** —— 据定案记录与已落地的实现整理,非当时原文。
- **影响面**:`packages/internal/src/schema/globals.ts` 的 `onboarding`、`apps/web/src/components/onboarding/`、`apps/web/src/pages/guide/`、系统页「新手指引」一节

## 背景

BN 的配置面比很多人用得上的宽:要登录 B 站、建连接、建推送目标、测一次、再订阅 UP 主 —— 五步都做完才有第一条推送。新用户开面板时面对的是一屏什么都还没有的空表。

难点不在「做一个导览」,在**它什么时候不该出现**:老用户升级上来,不该被一个教程糊脸。

## 决策

### 三态(2026-08-30 终稿,推翻了五轮时的「永久常驻无关闭态」)

1. 🔴 **`onboarding.skipped` 是三态,不是布尔**:
   - **缺失 = 还没问过** → 打开面板时屏幕中间弹询问框(新用户开始指引 / 老用户跳过)
   - `false` = 要指引 → 导览出现(左缘标签 ⇄ 小卡)
   - `true` = 不要 → 整个导览不渲染
2. 🔴 **「缺失」必须原样穿透,不许被 default 补成 false。** 补成 false 等于**永远不问、对老用户直接开导览** —— 那正是上一版被主人打回的行为。升级上来的存量实例与全新安装都落在「缺失」这一档。
3. **落配置,不落 localStorage。**「这台实例问过了没」是**实例级事实**,换台机器、换个浏览器开面板不该再被问一遍。
4. 写入 `skipped` 的路径只有三条:询问框选「老用户」、小卡上的「跳过指引」、走完五步毕业。系统页的「重新开启」写回 `false`。
5. **折叠态取值**:localStorage 优先,没存过才跟这个标记。

### 为什么非要有那个「跳过」按钮

6. 🔴 适配器那步的判据是 `enabled && testStatus?.ok`,而 **`testStatus` 只有用户手动按过「测试」才会写**。绝大多数老用户从没点过 → 升级后一律被判成「没配完」→ 导览自动展开 + 引导锁把面板锁到只剩聚光灯那一处。**这是审查里最伤现网的一条。**

### 步序与位置

7. **步序 = 登录 → 连接 → 推送目标 → 测试 → 订阅**(主人拍板)。理由在代码里坐实:订阅表单要勾推送目标,先订阅的话通道没就绪还得回头重编辑订阅。
8. **教程并进「关于」页**,不开独立路由与 nav 项:`/about/:section?/:chapter?`,深链给导览尾巴用。**别再提回独立路由 / nav 项。**
9. **页签被藏 = 导览死胡同**:nav 偏好只钉死 `/system`,`/targets` `/subs` 都能藏;藏了之后跨页步的 `[data-tour-nav]` 解析不到 → 灯不亮、锁不铺,小卡还在说「点亮起的页签前往」。主人拍板「确实遇到就降级出口」→ **只在该路由被藏时**把「带我去」按钮放回小卡。

## 明确不做(拷问中被否决的)

- **`onboardingDismissed` 那个老字段**:管的是「彻底关闭连标签都不留」,**已作废**且不会回来。这次的 `skipped` 只管「开面板要不要自动展开」,左缘标签照常常驻。
- **独立的 `/guide` 路由与导航项**:见决策 8。
- **导览永久常驻、完全没有关闭态**:五轮时的方案,08-30 被主人推翻。

## 后果

- 🔴 **`.dockerignore` 的 `**/*.md` 差点炸掉发版** —— guide 六章 markdown 是 `?raw` 静态导入,**是构建输入**;CI 的 build / typecheck 都不走 Docker,**拦不住**,只有 push `v*` tag 之后才炸。已加白名单。**以后再往 web 里 `?raw` 引任何非代码文件,先想一遍 dockerignore。**
- **`<div>` 包 `SectionNav` 会杀掉 sticky**:它的根是 `contents xl:block`,靠溶进 rail grid 才有吸附行程,中间夹一个盒子两个断点都失效。组件自己的注释写过这一条。

## 仍未决 / 未验

- **未发版**;导览各步的真机观感没走过一遍。
