# ADR-0002:皮肤包 —— 结构化 schema,不开 CSS 口子

- **状态**:**已实现并发版**(2026-08-14 经 `/grill-me` 八项拍板、同日落 dev;随 v0.7.0 发版 2026-08-25;此后多轮真机精简与语汇统一)
- **记录方式**:⚠️ **事后追认** —— 据定案记录与已落地的实现整理,非当时原文。
- **影响面**:`packages/ui/src/theme.css` 与全部组件的 `data-bn` 挂点、`apps/web` 的皮肤页与合成函数、`apps/contract/src/skin.ts`、`<dataDir>/skins/`
- **不影响**:桌面启动页、卡片渲染图(后者有模版编辑器的地盘)

## 背景

参照物是主人给的 Codex-Dream-Skin(壁纸 + 配色 + 受限 CSS 的 zip 包)。而 BN 的 dashboard 靠玻璃拟态架构(整页 `--bn-page-bg` 单变量 + `.bn-glass` 浮层)**天然已达其九成观感** —— 缺的只是「让用户换掉那几个变量」。

真正的设计问题是:**要不要开 CSS 口子。** 开了,皮肤能做的事没有上限,但换来的是「任何一次组件重构都可能悄悄弄坏别人的皮肤」。

## 决策

### 能力与范围(八项拍板)

1. 🔴 **能力路线 = 结构化 schema,不开受限 CSS。** `colors.* / wallpaper.* / glass.* / fonts.*` 语义化字段,服务端维护一张「字段 → 内部 `--bn-*` 令牌」的映射表。**要新花样就加字段。**
2. **范围只给 Web Dashboard。** 桌面启动页、卡片渲染图全部出圈。
3. **格式 = zip**(`skin.json` + `assets/`);但**引导页支持粘贴 JSON + 拖壁纸、前端自动组包** —— 普通用户不该碰压缩软件。
4. **明暗双套可选 + 单套锁模式**:只给一套时应用后锁定该模式、切换钮置灰。
5. **存储 = data 目录里的皮肤库**,多套收藏、列表切换 / 删除,「默认装」永远在列。
6. **预览 = 整页实时试穿**,本 tab 临时生效不落盘,浮条「应用 / 取消」,刷新还原;与正式应用**共用同一套前端合成函数**。
7. **逃生舱双保险**:`?skin=off`(会话级强制默认,不改服务端)+ 设置页恢复默认。
8. **「帮其他 AI 做皮肤」的载体 = 面板内置制作引导页**,一键复制「schema 规格 + 当前令牌值 + 提示词」粘给任意 AI。**不建仓库 skill**(SKINNING.md 方案被否)。

### 换肤契约(实现期长出来的硬约束,今天每次写 UI 都要遵守)

9. 🔴 **`data-bn` 挂点是公开 API。** 皮肤的自定义 CSS 只能瞄准 `SKIN_CSS_HOOK_MAP` 里的挂点,而这些挂点由组件真实背着属性(`btn` / `input` / `avatar` / `modal` / `nav` / `header` …)。**重构组件不许丢属性**;换真实选择器就改映射表,**hook 名只增不改**。
10. 🔴 **颜色走 token,不写字面值。** `accent="#FB7299"` 与 `accent="var(--color-bn-pink)"` 在默认装下像素级一致,差别只在装了皮肤之后 —— 前者永远钉在 B 站粉。守卫按「**同值**」而不是「是个 hex」判,因为站里有一批**刻意不跟皮肤**的产品语言色(推送家族色:直播是粉的、动态是蓝的)。
11. 🔴 **圆角走轴,不写死 `rounded-full`** —— 写死的话皮肤把 `radius.pill` 调到 0 求一身硬直角也掰不直它。真正必须是正圆的(头像、状态点)照写。
12. 🔴 **透明度走 `color-mix()`,不许拼 hex alpha 后缀。** `` `${accent}44` `` 有两个静默死法:传 `var()` 拼出非法值、传 3 位 hex 拼出错值,**都被浏览器直接丢弃、都不会红**。
13. 🔴 **实心底的按钮一律双挂点 `btn btn-primary`、前景走 `on-solid` token。** 单挂 `btn` 会被皮肤刷成中性底,实底前景浮上去就隐形 —— 爱发电按钮当年就是这么消失的。
14. **开关不许挂 `btn`**,走 `switch` / `switch-on` / `switch-dot`:挂 `btn` 的后果是皮肤的按钮实底盖掉轨道背景,开着的粉轨道和关着的灰轨道**变成同一个色**。
15. **静态可换肤的颜色必须走 class,不许落 `style={{}}`** —— inline 压过一切 author 样式,皮肤连覆盖的机会都没有,而且 **inline 没有 `:hover`**。只有「逐项动态的语义色」可以走行内。
16. **页级卡片容器一律玻璃底**,禁止实底或「只有边框全透明」的容器 —— 皮肤壁纸一开就穿帮。

### 手写皮肤 CSS 的规矩(2026-08-25 主人指正)

17. **`pointer-events` / `z-index` / 宿主定位一概不写。** 装饰的硬规矩(`pointer-events:none` + `z-index:-1`)**只住注入层**(带 `!important`),清洗层**只删不加**、`pointer-events` 一律照实报警。
18. 存量烙印由 store 读盘进索引时按签名摘掉(**不回写磁盘**,下次保存自然升级);旧 zip 导入仍会一次性报警 —— 那是诚实的,文件里真有。

## 明确不做(拷问中被否决的)

- **受限 CSS 口子**:见决策 1。要新能力就加 schema 字段。
- **仓库里放一份 `SKINNING.md` 给别的 AI 读**:改成面板内置引导页(决策 8)。
- **AI 联网帮用户找壁纸**(2026-08-19 主人整条砍掉):壁纸只剩两条来路 —— 聊天贴图、编辑器传图。
- **`skin.json` / `default.json` 合并成一份**(2026-08-19 主人拷问后拍板维持两份,四条理由在案):**别再提「太冗余」**。
- **四色预设**:已整体删除,别提回。
- **聊天玻璃透明度滑杆 / 完全透明**:已删。
- **banner / 粒子 / 贴纸**:全被砍,动效只剩流光 + 光斑,图片只剩壁纸。
- **字号阶梯进皮肤词表**:开了就是大字模式,而阶梯不是等比的(下半段 +1 密排、上半段越拉越开),没法像圆角那样一根系数整体缩放;逐档开九个键则挡不住有人把 `xs` 调得比 `sm` 大。**栏宽是反例,它开了** —— 单个数字、两头夹死、调坏了最多是左栏胖瘦。
- **叠放层级进皮肤词表**:皮肤重排叠放顺序只会把弹窗压到遮罩底下去。

## 后果

- **「编辑器 = 能力全集」是硬性原则**:schema 加字段就要同步加控件,砍字段就要同步砍控件。
- 🔴 **`@theme` 里不许放 shadow 族。** Tailwind v4 对 shadow 是**编译期内联**的(与 radius 保留 `var()` 引用相反),放进 `@theme` 会让换肤时阴影变成死链;所以 `shadow-bn-card` / `shadow-bn-elev` 是手写 `@utility`。同理**动 `box-shadow` 的动画必须把基础影合回 `--tw-` 链**,否则流光动画会吃掉卡片阴影。
- **日志控制台与代码块那块暗面刻意不进皮肤词表**(`--color-bn-console-*`):行内三档字色是照着那个底配的,皮肤把底调亮日志就没法读了。恒定 ≠ 写死 —— 它仍然集中在一处。
- 皮肤库出厂四套(两亮两暗),已按「亮 = 零特效零 shadows / 暗 = 流光 + 光斑 + 双层霓虹影」统一,并写进 AI 提示词。**盘上直改皮肤数据要重启 server。**
- 「装了皮肤后 XX 看不见」是个**会反复发生**的故障类型(两天内咬过 7 次,门禁全绿只有真机露馅),三类成因与修法记在 `packages/ui/README.md` 的维护约定里。
