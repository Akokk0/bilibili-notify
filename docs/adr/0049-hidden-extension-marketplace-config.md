# ADR-0049：第三方拓展的作者配置使用隐藏目录

- **状态**：2026-11-13 定案。
- **取代范围**：[ADR-0048](0048-extension-marketplace-config.md) 决策 1 中的配置目录。

## 背景

脚手架需要一处固定位置保存发布工具使用的市场资料。作者希望将这份工具配置放进隐藏目录，根目录仍可直接看到拓展清单和源码。

## 决策

第三方工程的新模板和发布工具统一使用工程根目录下的 `.bn-extension/marketplace.json`。沿用 ADR-0048 的作者资料格式和发布仓库推断规则。`bn-extension` 继续作为 CLI 命令名。

## 明确不做

发布工具只读取 `.bn-extension/marketplace.json`。官方拓展由主仓工作流生成市场条目，无需作者配置目录。

## 后果

本次 alpha 允许直接更换配置路径。新工程由创建器生成对应的目录和文件。
