Sources can offer account sign-in to read subscription content. Each source's accounts are managed separately.

1. Open [System → Accounts](/system#account), find the source under Source accounts, and select QR sign-in.
2. Scan and confirm in that source's client. You can close the dialog and use Continue QR sign-in to reopen the same code.
3. Once signed in, the row shows the new status. The guide checks the next source before moving on to push connections.

## Which account appears in the header?

The first account supplies the header and AI chat avatar. Drag the handles on the left to reorder accounts, then save. Discarding changes restores the previous order. With a handle focused, press Space to pick it up, use the arrow keys to move it, and press Space again to drop it.

If the first account is not signed in, its sign-in status is shown; BN does not substitute a later account. When no source offers sign-in, this step is unnecessary.

## Sign-in is not completing?

The page shows the status and explanation returned by the source. If a QR code expires, start sign-in again. If sign-out fails, the previous status remains and you can retry later.
