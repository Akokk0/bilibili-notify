Subscriptions decide which creators BN follows for you. Content updates, live notifications, and end-of-stream summaries start from the subscription list. This is the **last setup step**: first complete the [push-channel setup](/about/guide/push), because the subscription form asks you to select targets.

1. Open [Subscriptions](/subs), search for a creator by name or ID, and select Subscribe.
2. In the form, select the push targets you created. These determine where that creator's notifications go.
3. Configure each subscription's features as needed, such as content updates, live start/end notifications, and live-chat summaries.
4. With at least one subscription, all applicable guide steps are complete. Content updates and live starts are then sent automatically.
