Subscriptions decide which creators BN follows for you. Content updates and live notifications start from this list; available features depend on the selected source. This is the **last setup step**: first complete the [push-channel setup](/about/guide/push), because the form asks you to select targets.

1. Open [Subscriptions](/subs), click Add subscription, and select a source. Follow the input hint to search by a supported creator name, account ID, or profile link, then choose a result.
2. Select the push targets you created. These determine where notifications go.
3. Enable the content and live features supported by that source. Each subscription can override global settings.
4. Once you save at least one subscription, all applicable guide steps are complete. Notifications then follow that source's detection rules.

## Use an extension source

Under [Extensions](/extensions), install and enable a source compatible with your BN version.

- **Douyin** supports videos, photo posts, and live notifications. Sign in with a QR code under [System → Accounts](/system#account) first.
- **Huya** supports public live rooms without signing in. Search by room ID, room link, or nickname.
- **Weibo** requires QR sign-in and that the account follows the creator on Weibo. The first check establishes a baseline, and notifications cover posts that appear after it.

See each extension's documentation for accepted search inputs, notification types, and check intervals.
