AI is an optional addition to BN: live-chat summaries, commentary on content updates, weekly reports, and AI maid chat in the lower-right corner.

1. Open [AI](/ai) and add a provider under Model settings. Enter its API key and model. For an OpenAI-compatible endpoint outside the official service, choose Custom and enter its base URL.
2. Select the provider instance in Global settings, enable AI at the top of the page, and save. Send a message in the AI maid chat to verify that the model replies.
3. Enable the commentary and live-summary features you want. You can configure web search and push voice separately.

## Web search and voice

- Under Search, choose a backend and enable web search for the push features you want. DeepSeek search can reuse the API key of the active official DeepSeek instance.
- Under Maid voice, choose DeepSeek or a custom speech service, select a voice, and save before previewing it. The default delivery is text only. Targets with audio support can receive voice and text, or voice only. BN synthesizes the text the maid generated for the notification.
