AI 是 BN 的選用功能，包含直播聊天室摘要、作品評論、統計週報，以及右下角的女僕 AI 對話。

1. 開啟 [智慧女僕](/ai)，到「模型設定」新增服務商並填入 API 金鑰與模型。使用非官方的 OpenAI 相容端點時，選擇「自訂」並填入 Base URL。
2. 在全域設定選擇要使用的服務商，在頁面頂端啟用 AI 並儲存。從右下角開啟女僕 AI 對話並傳送訊息，確認模型能回覆。
3. 依需要開啟作品評論、直播摘要等功能。可分別設定網路搜尋與推播語音。

## 網路搜尋與語音

- 在「搜尋」選擇後端，依需要為個別推播功能開啟網路搜尋。DeepSeek 搜尋可沿用目前官方 DeepSeek 實例的 API 金鑰。
- 在「女僕聲線」選擇 DeepSeek 或自訂合成服務與音色，儲存後即可試聽。預設只傳送文字。支援語音的目標可選擇同時傳送語音與文字，或只傳送語音。朗讀的內容為女僕替該則推播產生的文字。
