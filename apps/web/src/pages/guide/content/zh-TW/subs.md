訂閱決定 BN 要追蹤哪些創作者。作品更新與直播通知都從訂閱清單開始，可用功能依選取的來源而定。這是初始設定的**最後一步**：表單需要選擇推播目標，請先依[推播通道](/about/guide/push)完成設定。

1. 開啟[訂閱](/subs)，點選「新增訂閱」並選擇來源，再依輸入欄提示，以支援的名稱、帳號 ID 或個人檔案連結搜尋並選取創作者。
2. 選擇先前建立的推播目標，決定訊息送往何處。
3. 開啟該來源支援且需要的作品、直播等功能；每個訂閱都能個別覆寫全域設定。
4. 儲存至少一個訂閱後，指引中適用的步驟即完成。後續通知依該來源的偵測規則傳送。

使用擴充功能來源時，請先到[擴充功能](/extensions)安裝並啟用；來源支援登入時，到[系統 → 帳號](/system#account)完成登入。搜尋輸入、通知類型、檢查間隔與首次是否補送既有作品，各來源可能不同，請依來源說明操作。
