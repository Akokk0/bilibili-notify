來源可以提供帳號登入，用來讀取訂閱內容。不同來源的帳號分別管理。

1. 開啟[系統 → 帳號](/system#account)，在「來源帳號」找到要登入的來源，按「掃碼登入」。
2. 使用對應來源的用戶端掃碼並確認。可以先關閉視窗，再按「繼續掃碼」開啟原本的代碼。
3. 登入成功後，該列會顯示已登入。新手指引會繼續檢查下一個來源，再進入推送連線設定。

## 頂欄顯示哪個帳號？

第一個帳號用於頂欄與 AI 對話頭像。拖曳左側把手即可排序，儲存後生效；放棄變更會恢復原順序。使用鍵盤時，先將焦點移到把手，按空白鍵拿起、方向鍵移動，再按空白鍵放下。

第一個帳號尚未登入時會顯示它的登入狀態，不會改用後面的帳號。沒有提供登入的來源時，不需要完成登入步驟。

## 登入沒有完成？

頁面會顯示來源回傳的狀態與原因。QR Code 過期後可重新發起登入；登出失敗時會保留原狀態，可以稍後重試。
