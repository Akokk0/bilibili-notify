AI 是 BN 的可选增强，可用来生成直播弹幕总结、作品点评和统计周报，也可在右下角与女仆聊天。

1. 打开[智能女仆](/ai)的「模型配置」，添加服务商并填写 API Key 和模型。使用非官方 OpenAI 兼容地址时，选择「自定义」并填写 Base URL。
2. 在「全局配置」选择要使用的服务商实例，在页首点「启用」并保存。打开右下角的女仆 AI 发一句话，即可确认模型能回复。
3. 按需开启作品点评、直播总结等功能。联网和推送语音可分别配置。

## 联网与语音

- 在「搜索」选择搜索后端，按需开启作品点评、直播总结或锐评联网。使用当前官方 DeepSeek 实例时，DeepSeek 搜索可沿用模型的 API Key。
- 在「女仆声线」选择 DeepSeek 或自定义合成服务，设置音色，保存后点「试听」。默认「仅文本」。支持语音的推送目标可以选择「语音＋文本」或「仅语音」，合成内容是推送中女仆生成的那段文字。
