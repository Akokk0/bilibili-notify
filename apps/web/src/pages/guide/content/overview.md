欢迎使用 bilibili-notify(BN)!这份指引带你从零走到「QQ 里收到第一条推送」。配置一共五步,左缘的「指引」导览会实时探测完成状态并自动推进,全部变绿就毕业啦。

1. **登录 B 站账号** —— 在「系统」页扫码,BN 用它拉取订阅 UP 的动态与直播状态。
2. **配置推送适配器** —— 把 BN 接上你的 QQ 机器人(或 webhook),并点「测试」验证连通。
3. **添加推送目标** —— 指定消息发到哪个群 / 哪个人。
4. **发送测试推送** —— 在目标上点「测试」,QQ 里收到消息即通道打通。
5. **订阅第一个 UP** —— 在「订阅」页搜索并添加想关注的 UP 主,订阅上即毕业。

为什么订阅放最后?订阅表单里就要勾选推送目标 —— 先把通道打通,订阅一步到位。

## QQ 接入选型:两条路怎么选

BN 支持两种接 QQ 的方式,**先选对路再动手**,它们的能力与成本完全不同:

| 判据 | qq-official(官方机器人) | onebot(NapCat 等协议端) |
| --- | --- | --- |
| **要不要群推送** | 按 bot 等级分层:扫码一键建的轻量 bot=自己私聊+自己当群主的群;过审 bot、企业主体逐级放宽(以官方政策为准) | ✅ 群聊 / 私聊都行,拉群自由 |
| **额外部署** | 零额外部署,BN 直连腾讯官方接口 | 要多跑一个协议端容器(NapCat / Lagrange) |
| **风控 / 封号风险** | 无 —— 官方 API,不碰你的 QQ 账号 | 协议端要登录一个 QQ 号,有风控与封号风险,建议用小号 |
| **消息形态** | 文字为主;图片要走可公网访问的 URL,markdown 受权限限制 | 图文自由,渲染出的卡片图直接发 |

一句话建议:**轻量自用** → 走 qq-official 的「扫码连接 / 创建」,五分钟搞定;**重度群推 / 想要图片卡片** → 走 onebot + NapCat。两条路的手把手教程都在[推送通道](/about/guide/push)一章。

不用 QQ?BN 还有 **webhook** 适配器(钉钉 / 飞书 / 企业微信 / 通用 JSON),同样在推送通道一章。
