图片渲染让推送从纯文字升级成漂亮的卡片图(动态卡 / 开播卡 / 总结卡)。**强烈推荐开启**,但不开也不影响毕业 —— 不开时 BN 自动退回文字推送。

## 按部署形态开启

**标准 Docker 镜像(默认)**:内置 Chromium,开箱即用 —— 到[卡片](/cards)页打开「图片渲染」开关,点「发送测试推送」看效果即可。

**slim 镜像**(tag 带 `-slim`):镜像里没有浏览器,需要在环境变量 `BN_CHROME_ENDPOINT` 指向一个远程浏览器(如 browserless 伴随容器),不配置则保持文字推送。

**非 Docker 部署**:在系统页配置本机 Chrome / Chromium 路径,或同样走远程浏览器。

导览「图片渲染」尾巴的判据是:渲染器可用**且**卡片渲染开关已打开。
