订阅决定 BN 帮你关注哪些创作者。作品更新和直播通知从订阅列表出发，可用功能由所选来源提供。这是初始设置的**最后一步**：表单需要选择推送目标，请先按[推送通道](/about/guide/push)一章把通道打通。

1. 打开[订阅](/subs)页，点击「添加订阅」，先选择来源，再按输入框提示输入昵称、账号 ID 或主页链接，搜索并选择创作者。
2. 在表单中选择此前建好的推送目标，决定消息发到哪里。
3. 开启所需且来源支持的作品、直播等功能；每条订阅可单独覆盖全局设置。
4. 保存至少一条订阅后，导览中适用的步骤全绿。后续通知按该来源的检测规则发送。

## 使用拓展来源

先在[拓展](/extensions)页安装并启用与当前 BN 版本兼容的来源。

- **抖音**在[系统 → 账号](/system#account)扫码登录后，可订阅视频、图文和直播。
- **虎牙**可直接订阅公开直播间。按输入框提示填写房间号、链接或昵称。
- **微博**需要扫码登录，并在微博上用该账号关注要订阅的博主。首次检查建立基线，此后出现的新微博才会推送。

搜索输入、通知类型与检查频率可在各拓展的说明里查看。
