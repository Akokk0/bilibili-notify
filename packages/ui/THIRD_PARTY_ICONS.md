# 第三方图形的来源

`src/icons.tsx` 里的平台 / 品牌图形不是自己画的,来源与许可如下。各家 logo 的商标归各家所有,
这里只用来标识「这是哪个平台」。

| 图标 | 来源 | 许可 |
|---|---|---|
| `qq`、`telegram`、`discord` | [Simple Icons](https://simpleicons.org) | CC0 1.0 |
| `feishu`(`lark`) | [IconPark](https://github.com/bytedance/IconPark)(ByteDance) | Apache-2.0 |
| `dingtalk`(`dingding-fill`) | [Remix Icon](https://remixicon.com) | Apache-2.0 |
| `wecom`(`wechat-work-filled`) | [Ant Design Icons](https://github.com/ant-design/ant-design-icons) | MIT |

其余图标是仓库自己画的(`.bn-design/shared.jsx` 那一套)。
